Bootstrap Structure and Setup

CSS Folder

Contains all Bootstrap stylesheets, utilities, grids, and minified variations (`bootstrap.min.css`).

JS Folder

Contains JavaScript plugins for components like modals, popovers, and accordions (`bootstrap.bundle.min.js`).

Icons Folder

Contains font files and CSS configurations for embedding Bootstrap Icons inside custom interfaces.

NPM and Sass Customization

npm install bootstrap
npm install bootstrap-icons
npm install -D sass
npx sass scss/custom.scss css/custom.css
