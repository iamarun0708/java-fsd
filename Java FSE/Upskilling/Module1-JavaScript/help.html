Chrome DevTools Usage

  • Open Developer Tools by pressing F12 or Ctrl+Shift+I.
  • Go to the Console tab to view runtime execution errors and logged messages.
  • Go to the Sources tab to add breakpoints in `main.js` and inspect values.
  • Go to the Network tab to monitor AJAX requests and fetch payloads.
